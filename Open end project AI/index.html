What is XR PhysicsLab?

XR PhysicsLab is an immersive, browser-based educational platform that simulates a Virtual Reality Physics Laboratory. Using Three.js for 3D rendering and real-time physics calculations, students can conduct experiments that are difficult, dangerous, or expensive in a real lab.

  • 🎮 Real-time 3D physics simulation
  • 🔬 5 complete experiment modules
  • 📊 Live data graphs and readings
  • 🧪 Interactive equipment manipulation
  • 📝 Built-in quizzes and assessments
  • 🌐 WebXR-ready architecture
